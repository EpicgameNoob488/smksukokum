# Product

## Register

product

## Users

Teachers and administrators at SM Konven St. Ursula (a Catholic convent secondary school). Teachers use the dashboard daily for inputting PAJSK cocurriculum scores and looking up student records. Administrators manage school-level data, teacher directories, and bulk imports. Both groups share the same tool but have different permission levels — the interface must serve both without feeling like either is an afterthought.

## Product Purpose

Track PAJSK cocurriculum scores and manage the student/teacher directory for SM Konven St. Ursula. Every day is a mix of data entry (score input, attendance recording) and reference lookups (student profiles, class rosters, teacher assignments). The dashboard replaces paper-based or siloed tracking with a single, warm, supportive surface that teachers at any technical comfort level can use without training.

## Brand Personality

Clear, Supportive, Warm

The tool is not clever. It's not playful. It does not demand attention. It sits quietly in the corner of a teacher's day — reliable, predictable, and gently warm. Teachers have enough complexity in their classroom; the dashboard should not add to it.

## Anti-references

No strong anti-references. The design should avoid the generic-ed-tech cliches (cartoonish icons, blackboard motifs, childish colors) while also steering clear of cold enterprise-SaaS density. Familiarity and warmth over novelty.

## Design Principles

- **The tool disappears into the task.** Teachers switch between score entry and record lookup constantly. Navigation, labels, and layout must be so predictable that they never require conscious interpretation. The interface earns its keep by being ignorable.

- **Clarity over cleverness.** Every heading, label, and data point says exactly what it means. No branded metaphors, no gamified language, no tonal surprises. "Clear" is the first personality word for a reason.

- **Warmth through restraint.** The cardinal red and deep indigo palette provides warmth without whimsy. Generous rounded corners and system fonts make the tool feel supportive, not sterile. Restraint is what separates warm from cloying.

- **Data with dignity.** Student records are personal. Scores, attendance, and notes are presented in a clean, respectful surface — never cramped, never flashy. The visual hierarchy puts the data forward and the chrome behind it.

- **Familiar first.** System fonts, standard form controls, platform-native scroll and focus behaviors. Teachers should never wonder "how do I use this thing" — they already know, because it works like every other tool they've used.

## Accessibility & Inclusion

Target WCAG AA. Minimum 4.5:1 contrast for all text, proper keyboard navigation with visible focus indicators, semantic HTML for screen readers, and responsive layouts that work across the desktop and tablet devices teachers carry day-to-day.
